# MSP-1 Schema Architect

This repository contains the canonical definition of the **MSP-1 Schema Architect** role.

The Schema Architect is a protocol-aware assistant role responsible for generating, validating, and reasoning about MSP-1 declarations in alignment with the MSP-1 specification and schemas.

This definition is maintained independently of any specific LLM platform.  
Variations in behavior across models may reflect stylistic differences, not differences in MSP-1 capability or protocol support.

## Scope
- Defines the Schema Architect role and guardrails
- Provides a reference system prompt used in practice
- Serves as a starting point for adaptation to other LLM environments

## Out of scope
- Protocol definition (see `msp-1-spec`)
- Canonical schemas (see `msp-1-schemas`)
- Validation enforcement or governance
